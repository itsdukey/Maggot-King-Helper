# Maggot King Helper

Hides various objects in the Maggot King arena.

## What this actually does

This plugin doesn't let you do anything you couldn't already do yourself, you could use [Object Hider](https://github.com/LuxOG/custom-object-hider) to hide carrion or Darkwood trees one at at time, even using the trees outside instance to hide the ones inside as they are the same id's. This plugin doesn't add new capability on top of that; it just:

- Bundles the specific objects that clutter the Maggot King fight into one-click toggles, instead of hiding them individually one by one.
- Scopes the hiding to the Maggot King arena instance only, so the same trees and scenery outside the fight are left untouched.
